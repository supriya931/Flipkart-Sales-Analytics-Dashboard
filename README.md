# Flipkart Sales Analytics Dashboard

## Project Overview
This project analyzes Flipkart sales data using Python and Power BI. The goal is to identify sales trends, top-performing products, customer behavior, and payment insights through interactive dashboards.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI

## Project Workflow
1. Data Cleaning using Python
2. Exploratory Data Analysis (EDA)
3. Data Visualization
4. Interactive Dashboard Creation in Power BI

## Key Insights
- Electronics category generated highest revenue.
- UPI is the most used payment method.
- High-rated products have better sales performance.
- Monthly sales trends were analyzed.

## Dashboard Features
- KPI Cards
- Category-wise Sales Analysis
- Monthly Sales Trend
- Payment Method Analysis
- Top 10 Products Table
- Rating vs Sales Analysis
- Interactive Slicers
